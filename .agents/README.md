# Agentes do Projeto RATE.IO

Este diretorio define perfis de agentes especializados para apoiar desenvolvimento com IA.

Use os perfis como instrucoes de contexto ao delegar tarefas:

- `architecture-agent.md`: decisoes arquiteturais e impacto entre dominios.
- `backend-agent.md`: API, persistencia, seguranca e regras financeiras.
- `frontend-agent.md`: React, rotas, estado de auth e integracao com API.
- `qa-agent.md`: testes, regressao, contratos e cenarios criticos.

Todos os agentes devem ler `.codex/project-context.md` e `docs/14-Relatorio Tecnico de Desenvolvimento e Arquitetura.md` antes de propor mudancas grandes.
