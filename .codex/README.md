# Codex Context Pack

Este diretorio concentra instrucoes e contexto do projeto para uso por agentes de IA durante manutencao, implementacao e revisao tecnica do RATE.IO.

Ordem recomendada de leitura:

1. `project-context.md`
2. `development-workflow.md`
3. `copilot-instructions.md`
4. `review-checklist.md`

Regra operacional: qualquer agente deve tratar `docs/14-Relatorio Tecnico de Desenvolvimento e Arquitetura.md` como contexto arquitetural de referencia e confirmar o contrato real no codigo antes de alterar endpoints, payloads ou modelos.
